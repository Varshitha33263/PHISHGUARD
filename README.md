\# PHISHGUARD – Phishing URL Risk Classification



\## About the Project

PHISHGUARD is a Machine Learning project that predicts whether a website URL is likely to be legitimate or phishing.



\## Technologies Used

\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- Random Forest Classifier

\- Streamlit

\- Jupyter Notebook



\## Project Files

\- `Project.ipynb` – Model development and analysis

\- `app.py` – Streamlit application

\- `phishing\_model.pkl` – Trained Machine Learning model

\- `feature\_names.pkl` – Feature names

\- `phishing\_site\_urls.csv` – Dataset

\- `PHISHGUARD\_Data\_Science\_Project\_Report.docx` – Project report



\## How to Run

```bash

python -m streamlit run app.py

```



Open `http://localhost:8501` in your browser.



\## Disclaimer

Predictions are ML-based estimates and do not guarantee website safety.
